## Key Profile Options

| Code | Purpose |
|------|---------|
| `ORA_ASE_SAS_INTEGRATION_ENABLED` | Enable Security Console for permission groups |
| `ORA_HCM_VBCS_PWA_ENABLED` | Enable VBCS Progressive Web Application UI |
| `ORA_PER_GUIDED_JOURNEYS_SETUP_REDWOOD_ENABLED` | Agent Task Type for Guided Journeys |
| `ORA_PER_AGENT_TASK_TYPE_GUIDED_JOURNEYS_ENABLED` | Redwood Guided Journey Setup Page |

## Key Privileges

| Privilege Code | Description |
|---------------|-------------|
| `HRC_MANAGE_AI_AGENT_PRIV` | Manage intelligent agents, tools and documents |
| `HRC_ACCESS_AI_AGENT_CHAT_PRIV` | Access intelligent agent chat component |
