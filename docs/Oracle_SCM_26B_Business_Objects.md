**Tool Call Sequence:**
```
1. Inventory Organization Lookup     → resolve org name/code → SourceOrganizationId
2. Get Accessible Organizations      → list orgs accessible from source
3. Get Org Level Quantities          → get AvailableQuantity for item in source org
4. Get Item Supply and Demand Summary → (optional) supply/demand per accessible org
5. Get Item Availability Summary     → (optional) availability per accessible org
6. Get Interorganization Parameters  → get TransferOrderRequiredFlag + IntransitTypeMeaning
7a. Create Transfer Order            → POST: Transfer Order (Procedure A)
7b. Item all transactions            → POST: In-Transit Shipment (Procedure B, pTransactionTypeId=21)
7c. Item all transactions            → POST: Direct Org Transfer (Procedure C, pTransactionTypeId=3)
8.  Supply Request UI Deep Link      → DeepLink after Transfer Order success
    Transaction Details Page         → DeepLink after In-Transit/Direct Transfer
```

**Decision Tree (Step 4 — Get Interorganization Parameters):**
```
TransferOrderRequiredFlag = true
  → Always create Transfer Order (Procedure A)

TransferOrderRequiredFlag = false + IntransitTypeMeaning = "In transit"
  → Ask user: Transfer Order OR In-transit Shipment

TransferOrderRequiredFlag = false + IntransitTypeMeaning = "Direct"
  → Ask user: Transfer Order OR Direct Organization Transfer
```

**Key Rules:**
- Never ask user for transfer quantity — always use full `AvailableQuantity`
- Never display internal IDs (`OrganizationId`, `ItemId`) to user
- Always wait for user response before proceeding to next step
- Partial quantity transfers not supported — redirect user to manual creation
